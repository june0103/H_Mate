### ModelParameter

> 원문: https://document.pleos.ai/docs/pleos-only/connect-sdk-pleos/LLM/l-l-m/ai.pleos.playground.llm.data/model-parameter/entry

`enum ModelParameter: Enum<ModelParameter>`
Enum class representing the available model parameters for the LLM service. This class defines the types of parameters that can be set via the setModelParameter function.

**Entries**
- `TEMPERATURE` — The TEMPERATURE parameter controls the randomness of the model's output.
- `MAX_TOKENS` — The MAX_TOKENS parameter defines the maximum number of tokens generated by the model.
- `MODEL_NAME` — The MODEL_NAME parameter specifies the name of the language model to be used.

**Properties**
- `entries` — Returns a representation of an immutable list of all enum entries, in the order they're declared.
  - `val entries: EnumEntries<ModelParameter>`
- `name`
  - `val name: String`
- `ordinal`
  - `val ordinal: Int`

**Functions**
- `valueOf` — Returns the enum constant of this type with the specified name. The string must match exactly an identifier used to declare an enum constant in this type. (Extraneous whitespace characters are not permitted.)
  - `fun valueOf(value: String): ModelParameter`
- `values` — Returns an array containing the constants of this enum type, in the order they're declared.
  - `fun values(): Array<ModelParameter>`

### LLM

> 원문: https://document.pleos.ai/docs/pleos-only/connect-sdk-pleos/LLM/l-l-m/ai.pleos.playground.llm/l-l-m/entry

`class LLM(context: Context, mode: Mode = Mode.SERVER)`
Supports API and callback for using LLM

**Constructors**
- `LLM`
  - `constructor(context: Context, mode: Mode = Mode.SERVER)`

**Types**
- `Companion`
  - `object Companion`

**Functions**
- `generateContent` — Generates content
  - `@RequiresPermission(value = "pleos.car.permission.LLM_SERVICE") fun generateContent(prompt: String, listener: ResultListener)`
- `getOnDeviceModelPromptsContents` — Gets the prompt content of the Model This API is only supported when the application is in ON_DEVICE mode.
  - `@RequiresPermission(value = "pleos.car.permission.LLM_SERVICE") fun getOnDeviceModelPromptsContents(): String`
- `initialize` — Initialize LLM SDK When the app starts or is created, it should call the initialization of SDK
  - `@RequiresPermission(value = "pleos.car.permission.LLM_SERVICE") fun initialize()`
- `registerApp` — Registers the app in SERVER mode.
  - `@RequiresPermission(value = "pleos.car.permission.LLM_SERVICE") fun registerApp(clientID: String, clientSecret: String, listener: OnServerConnectionListener)`
- `release` — Release LLM SDK When the app terminates or is destroyed, it should call the release of SDK
  - `@RequiresPermission(value = "pleos.car.permission.LLM_SERVICE") fun release()`
- `sendMessage` — Sends messages in the conversation Users can receive responses to messages
  - `@RequiresPermission(value = "pleos.car.permission.LLM_SERVICE") fun sendMessage(inputContent: LLMContent, listener: ResultListener)`
- `setModelParameter` — Sets the model parameters which control the behavior of the LLM model in SERVER mode. This API is only supported when the application is in SERVER mode.
  - `@RequiresPermission(value = "pleos.car.permission.LLM_SERVICE") fun setModelParameter(type: ModelParameter, value: String, listener: ResultListener)`
- `setServerType`
  - `fun setServerType(type: Int)`
- `startChat` — Start a chat conversation in a new session
  - `@RequiresPermission(value = "pleos.car.permission.LLM_SERVICE") fun startChat(history: List<LLMContent> = listOf(), onSuccess: () -> Unit, onFailed: (reason: String) -> Unit)`
